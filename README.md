# Copy Selected Tab URLs

Chrome extension that copies the URLs of all selected (highlighted) tabs in the current window to the clipboard, one per line.

## Install (unpacked)

1. Open `chrome://extensions` and enable **Developer mode**.
2. **Load unpacked** → select this directory.

## Use

Select tabs (Cmd/Ctrl-click or Shift-click), then click the toolbar icon or press **Alt+Shift+C**. Change the shortcut at `chrome://extensions/shortcuts`.

## Releasing

1. Bump `version` in `manifest.json` (the store rejects re-used versions).
2. Tag and push: `git tag v<version> && git push origin v<version>`.
3. The `release` workflow checks the tag matches the manifest, builds `copy-tab-urls-<version>.zip` and attaches it to a GitHub release.
4. Upload that zip in the [Chrome Web Store developer dashboard](https://chrome.google.com/webstore/devconsole) (automated upload to come).

Package locally with `scripts/package.sh`. Icons are generated by `uv run scripts/make_icons.py`.
